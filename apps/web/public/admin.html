    Live diagnostic system · production

    What a live test touches

    • Each message goes to the production diagnostic system — one ac2 turn on the diagnosis engine — exactly as a customer message would, using the advisor model currently set in Settings.
    • Turns belong to one conversation: like a customer’s browser, the Live Test sends back the signed conversation-state token the API returned, so the conversation record (appliance, hazards, outcome) carries from turn to turn. The token stays in this browser tab only and is never shown. New conversation discards it.
    • No conversation transcript is saved and nothing in Knowledge, Error Codes, Media or Safety changes. The diagnostic engine keeps its usual time-limited conversation state, as it does for every caller.
